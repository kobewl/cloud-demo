## 二、Windows 侧部署步骤

### 1. 安装 Docker Desktop（用于跑 Nacos）

- 下载：https://www.docker.com/products/docker-desktop/
- 安装时勾选 **Use WSL 2 instead of Hyper-V**（需 Windows 10 22H2+ / Windows 11，BIOS 开虚拟化）
- 验证：`docker version`
- 注意：Docker Desktop 启动后容器才跑，开机需手动启动

### 2. 启动 Nacos 容器

```bat
docker run -d --name nacos ^
  -p 8848:8848 -p 9848:9848 -p 9849:9849 -p 18080:8080 ^
  -v nacos_data:/home/nacos/data ^
  -e MODE=standalone ^
  -e NACOS_AUTH_ENABLE=true ^
  -e NACOS_AUTH_TOKEN=YourSecretKeyAtLeast32Chars1234567890 ^
  -e NACOS_AUTH_IDENTITY_KEY=serverIdentity ^
  -e NACOS_AUTH_IDENTITY_VALUE=security ^
  nacos/nacos-server:v3.2.3
```

（PowerShell 不支持 `^` 续行，直接写成一行即可）

**版本选择说明**：
- 用固定 tag **`v3.2.3`**（当前 3.x 最新稳定版，2026-07-14 发布）
- **不要用 `latest`**：官方已把 `latest` 指向 3.3.0-BETA 快照，行为不可控
- 本项目客户端是 SCA 2023.0.3.2 内置 nacos-client 2.3.x，**官方兼容性表确认 3.x 服务端兼容 2.x 客户端**（已在 Mac 上实测通过）
- 需要 Nacos 控制台时用固定 tag 时，Mac 上本地容器是 `nacos/nacos-server:latest`（实际解析到 3.2.1）

**参数说明**：
- `-v nacos_data:/home/nacos/data`：数据卷，删容器配置数据不丢（**务必保留**）
- `NACOS_AUTH_ENABLE=true`：开启鉴权，登录账号 nacos/nacos
- `NACOS_AUTH_TOKEN`：鉴权密钥，**必须 ≥32 字符**（2.2.1+ 无默认值，不设启动报错）

验证：
```bat
docker ps        # nacos 容器状态 Up
```

### 3. 安装 MySQL 8 Community Server（原生）

- 下载：https://dev.mysql.com/downloads/mysql/ → MySQL 8.0.x for Windows
- 安装选 **Server only**，root 密码设 **`12345678`**
- 勾选 **注册为 Windows 服务 + 开机自启**（7×24 服务器必选）
- 验证：`netstat -ano | findstr 3306`

### 4. 配置 MySQL 远程访问（关键！）

MySQL 原生安装默认只允许本机连接，必须建远程账号才能让 Mac 连上。

```sql
-- Windows 本机执行：mysql -uroot -p12345678
CREATE USER 'root'@'%' IDENTIFIED BY '12345678';
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;
```

### 5. 创建业务数据库

```sql
CREATE DATABASE IF NOT EXISTS product_db DEFAULT CHARACTER SET utf8mb4;
CREATE DATABASE IF NOT EXISTS stock_db DEFAULT CHARACTER SET utf8mb4;
-- order_db 不需要手动建：service-order 的配置带 createDatabaseIfNotExist=true，启动自动建
```

> 表结构不需要手动建：每个服务启动时 `spring.sql.init.mode: always` 会自动执行
> `classpath:db/schema.sql`（`CREATE TABLE IF NOT EXISTS`，幂等）。

### 6. Windows 防火墙放行（管理员 CMD）

```bat
netsh advfirewall firewall add rule name="Nacos8848" dir=in action=allow protocol=TCP localport=8848
netsh advfirewall firewall add rule name="Nacos9848" dir=in action=allow protocol=TCP localport=9848
netsh advfirewall firewall add rule name="Nacos9849" dir=in action=allow protocol=TCP localport=9849
netsh advfirewall firewall add rule name="Nacos18080" dir=in action=allow protocol=TCP localport=18080
netsh advfirewall firewall add rule name="MySQL3306" dir=in action=allow protocol=TCP localport=3306
```

> **最容易漏的一步**：Docker 端口默认绑 0.0.0.0，但 Windows 防火墙不放行，局域网照样连不上。

## 三、Mac 侧使用方式

### 1. 验证连通性（先于启动服务）

```bash
ping 10.110.0.170
nc -zv 10.110.0.170 3306    # MySQL
nc -zv 10.110.0.170 8848    # Nacos HTTP
nc -zv 10.110.0.170 9848    # Nacos gRPC（注册/配置拉取主要走它）
```

### 2. 发布配置到 Windows Nacos

Windows 的 Nacos 是全新实例，**里面没有配置**，需要把 `docs/nacos-config/` 下的
`service-product.yaml` / `service-stock.yaml` / `service-order.yaml` 发布过去。
（Nacos 3.x 的发布接口是 v3，见下方命令模板）

```bash
# 在 Mac 上执行（把 WIN_IP 换成 10.110.0.170）
TOKEN=$(curl -s -X POST "http://10.110.0.170:8848/nacos/v1/auth/login" \
  -d "username=nacos&password=nacos" | python3 -c "import sys,json;print(json.load(sys.stdin)['accessToken'])")

for f in service-product service-stock service-order; do
  curl -s -X POST "http://10.110.0.170:8848/nacos/v3/admin/cs/config" \
    -H "Authorization: Bearer $TOKEN" \
    --data-urlencode "dataId=$f.yaml" \
    --data-urlencode "groupName=DEFAULT_GROUP" \
    --data-urlencode "content@docs/nacos-config/$f.yaml"
  echo " <- $f"
done
```

### 3. 启动业务服务（Mac 上）

```bash
# 默认值已指向 Windows（application.yml 里 NACOS_ADDR 默认 127.0.0.1 需覆盖）
NACOS_ADDR=10.110.0.170:8848 mvn -pl services/service-product spring-boot:run
NACOS_ADDR=10.110.0.170:8848 mvn -pl services/service-stock spring-boot:run
NACOS_ADDR=10.110.0.170:8848 mvn -pl services/service-order spring-boot:run
```

- `NACOS_ADDR`：Nacos 所在机器地址（Windows）
- `NACOS_IP`：如无多网卡问题可不设（占位符 `${NACOS_IP:}` 默认空）
- `MYSQL_HOST`：配置中心里的 datasource 已默认 `10.110.0.170`，一般不用再传

### 4. 查看注册与配置

- Nacos 控制台：`http://10.110.0.170:18080`（nacos/nacos）
- 看到 product/stock/order 三个服务各注册了实例，配置列表有 3 份 yaml 即成功

## 五、踩坑记录

1. **`Host '...' is not allowed to connect`**：MySQL 没建远程账号。解决：`CREATE USER 'root'@'%' ...` + `GRANT` + `FLUSH PRIVILEGES`。
2. **`Unknown database 'product_db'`**：Windows MySQL 是全新安装，需手动 `CREATE DATABASE`。表不用建，schema.sql 自动建。
3. **密码不匹配时的报错特征**：`ERROR 1045 (28000): Access denied` 是密码/账号错；
   `ERROR 1130 (HY000): Host ... not allowed` 是权限问题（没建远程账号）。两者别搞混。
4. **Nacos 3.x OpenAPI 大改**：发布配置用 `POST /nacos/v3/admin/cs/config`（参数 `groupName`，
   鉴权 `Authorization: Bearer <token>`），v1/v2 的 `/cs/config` 路径已移除（404）。
5. **`nacos/nacos-server:latest` 不要在生产用**：官方已把 latest 指向 3.3.0-BETA 快照，用固定 tag `v3.2.3`。
6. **Mac 上 Shell 工具里 nohup 启动的服务命令返回后会被回收**：验证要"启动+等待+curl"放同一条命令里。
7. **Nacos 3.x 鉴权默认**：客户端鉴权（`nacos.core.auth.enabled`）默认关，控制台鉴权默认开。
   启动 Nacos 时开鉴权（`NACOS_AUTH_ENABLE=true`）则两边行为一致，客户端账号密码 nacos/nacos 照常使用。

## 六、日常运维

| 操作 | 命令 |
|------|------|
| 看 Nacos 容器状态 | `docker ps` / `docker logs nacos` |
| 重启 Nacos | `docker restart nacos` |
| 看 MySQL 服务状态 | 服务管理器里找 MySQL80，或 `netstat -ano \| findstr 3306` |
| 改业务配置 | 编辑 `docs/nacos-config/*.yaml` → Nacos 控制台同步 → 服务 `@RefreshScope` 自动生效 |
| 停 Mac 本地 Docker 基础设施 | `docker stop nacos mysql`（迁移完成后 Mac 不再承担服务器角色） |
